Capture stutter fix for **60 FPS games with V-Sync**, now based on **OBS Studio 33.0.1**. The fixes are the same as in v1.2.0 (OBS 32.2.2). [What it fixes and what not →](https://github.com/veelasama/obs-studio-capture-stutter-fix#is-this-build-for-you)

> [!IMPORTANT]
> **Before the first recording:** Settings → Video → Match Display → **Measure and Set**. Step-by-step: [Setup](https://github.com/veelasama/obs-studio-capture-stutter-fix#setup).

> [!WARNING]
> **Capture Method must not be *Automatic*.** Window Capture → **Modern (WGC)** · Display Capture → **Legacy (DXGI)** or **Modern (WGC)**. BitBlt is not fixed.

> [!NOTE]
> **Updating from an earlier version:** uninstall it first, then install this one. Your settings are kept.

> [!CAUTION]
> The installer is not code-signed, so Windows SmartScreen will show an "Unknown publisher" warning. Verify the file with `SHA256SUMS.txt`.
